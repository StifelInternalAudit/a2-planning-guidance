# A2 Planning Guidance

This repository publishes the Stifel Internal Audit A2 Audit Planning Methodology through GitHub Pages.

The GitHub Pages landing page is:

https://stifelinternalaudit.github.io/a2-planning-guidance/

Primary files:
- `index.md` contains the full methodology and should be used as the landing page.
- `sections.md` contains Sections 6 through 15.
- `build.md` contains Sections 16 and 17.
- `validation.md` contains Sections 18 and 19, followed by Appendices A through C.

The Markdown files intentionally wrap the methodology text in fenced `text` code blocks so GitHub Pages preserves the plain-text layout and does not reinterpret the methodology as Markdown headings, ordered lists, or HTML.
